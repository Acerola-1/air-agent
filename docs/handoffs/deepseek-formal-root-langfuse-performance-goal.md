## 正文时间和质量

从用户发送到首次用户可见的有用正文、首次可核验结果、完整结束、期间最长无正文时间分别记录；工具正在调用、心跳、推理、工具参数、空泛开场或复述不算有效正文。接口 SSE 到达与浏览器真实绘制分别计时，浏览器未测就写未采集。

当前产品已撤回新增语义单元；原始 answer 流按 legacy 口径单列。保留原始事件时间与受控答案，抽样人工复核“首有用正文”判据并记录方法；无法可靠区分首核验结果时填未采集，不用最终正文时间代填，不填零，不为凑指标修改产品。传统首 answer token、按内容复核的首有效正文和浏览器可见时间不能混合计算 P95。

技术流完成、业务有效、答案质量合格分别统计分母。真实结果按本轮获准工具返回与实际日期范围核对，不能套用合成 fixture 的数值和时刻；Q4 可信历史已能作答时不机械要求重查工具。保留失败样本、原始评分和缺失证据。

- 模型 generation、工具调用、Skill 加载/执行及父子关系是否存在；缺哪层就写哪层，未使用子图/子任务不编造覆盖。
