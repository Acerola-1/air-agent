## 数据与运行限制

- 数值是合成语义fixture，不是已接通的MCP响应，不是实际空气质量，也不是AQI法规映射校准向量。当前法规参考不完整，模型对浓度/AQI关系发出有根据的告警应保留，不能为了gold压掉告警或用测试数据证明法规正确。
- BQA-014/019/030/038依赖固定今日分支时钟；真实E层不能篡改北京时间冒充同一今日分支。Q4历史必须由隔离运行支持的授权方式装载，不能伪造已执行历史。
- 本轮没有可用性已验证的完整隔离BFF/官方平台/IAM/PG测试栈及fixture适配执行器，故没有向正式业务库提交40题、没有调用真实业务MCP，也没有改变共享服务/正式凭据。不能把本离线命令视为完整性能入口。
- `station-extreme`正文与工具声明不一致，部分Skill的图表要求与allowed-tools不一致，已在题库标明待实测接缝；静态阅读不足以判定真实运行一定失败或成功。
