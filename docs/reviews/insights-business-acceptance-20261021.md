## 协调者发现并修复

| 问题 | 修复与验证 |
|---|---|
| worker用会话级GUC，池连接可能遗留上个任务企业 | 每事务本地GUC，任务后续事务重新设置；单连接复用正反对照验证任务内有效、归还后无tenant/worker上下文 |
| 授权只检查逻辑调用，物理重试和临界LLM复核缺检查 | 每次HTTP发送前均复查；受控503后模拟撤权，实际HTTP测试替身只收到第一次发送 |
| 分类已提交后才更新作业进度，旧fence仍可能留下结果 | 结果与进度同事务，锁住当前有效租约后一起提交；失效owner/fence反例无intent/cluster落库，合法租约正向成功且进度恰好1 |
| 一批之后直接completed，累计预算未计入下一批 | 未耗尽来源保持pending，预算从既有用量累计；一批1条的合成场景处理完2条才结束，已达预算时不启动下一批 |
| 前序未确认请求卡住发现水位、重试跨作业窗口 | 发现阶段推进(admitted_at,id)，缺口独立回看；重试限制在当前窗口与尝试上限；前序未确认仍允许后续两条合法问题完成 |
| 空连续作业立即产生后继，反复空扫描 | 后继及再次pending领取遵守轮询间隔；有效租约不可由过期持有者续约 |
| 模型结果宽松转换/截断、重复意图与敏感输出 | 拒绝非法/多余字段、超限/空文本、字符串否定和bool置信度；输出重新脱敏与去重；向量拒绝bool/非有限范数；14个新增合成回归场景覆盖相关边界 |
| 复核输出可选择不兼容簇，单条多意图建簇后候选未刷新 | LLM只能在仍兼容且待复核的候选中选择；新建簇后刷新候选/容量；部署embedding/normalizer必须匹配冻结profile |
| 修订号0被or -1当成缺失 | 0可正常匹配，撤权仍拒绝；受控身份正反对照 |
| 到期内容在清理前仍可能进入统计/来源 | 新增前向迁移0029的restrictive RLS，过期或墓碑立即禁读来源/意图/派生正文；自有PG从[1,1,1]变[0,0,0]，不等待物理清理 |
| 无有效委托时清理可能停滞 | worker独立于分析授权按企业有界轮转清理；分析前亦清理过期原型，测试验证物理来源删除 |
| 页面表单与拆分两步操作可能残留旧scope | 复用useScopeKey与路由重建页面，旧页面拆分预览返回后不继续提交；本轮只做代码/类型/构建/静态审查，真实浏览器验证后置 |
| 共享OpenAPI冻结未同步 | 核对已有33条路径逐条不变，仅增加27条console/insights路径后重新冻结，原漂移断言保持有效 |
