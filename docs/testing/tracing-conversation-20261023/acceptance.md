# 智能溯源会话路由实施与验收

日期：2026-10-23，北京时间。变更：`add-tracing-conversation-routing`。分支 `dev`，基线及验收时 HEAD 均为 `0b3c4bf13b26ec26b8aaa93fb06c7bb5ffb8059d`；实现留在工作区，没有提交、推送、部署或归档。

## 实现结果

- 每个用户回合先由现有主模型提交严格意图计划，服务端决定普通交流、精确澄清或正式分析。不采用问候关键词路由，也不因为历史报告存在而跳过本轮判断。
- 问候和能力介绍由版本化可信条目组合成完整回复；模型自由正文仍不可见。此阶段支持条目选择、排序和受控语气，不承诺任意自由改写。
- 草稿只接纳当前用户原文支持的字段，明确续接才能跨轮合并；完整且合法后才允许授权站点目录解析，再由实际冻结结果开放专员、知识及报告工具。
- 执行决定绑定 run、attempt、消息摘要及用户/企业/会话/图/上下文版本。正式分析继续使用既有证据门禁和分节发布；普通交流不生成报告 artifact。
- 普通交流、澄清及分析共用终答协议和生命周期检查；新分析清空上一分析的发现及发布会话，历史已确认报告保留。内部 `submit_tracing_turn` 在实时/历史界面均隐藏，实际查询工具仍显示。
- 真实模型回归修复了完整时间引用校验：同一句中多个时间端点分别核验，不能只比较第一个日期，也不能忽略分钟或偏移。补充了中文数字半径校验。

这次未修改异常基线、24 小时均值、污染成因或报告信息密度算法。最初北区建设指挥部报告内容不足的问题，需要另行针对真实源数据和统计链路排查。

- 23 个受影响 Python 文件的 Ruff 检查及格式检查通过，见 `ruff-check-01.txt`、`ruff-format-01.txt`。所有工作区 diff 的空白检查通过。
- 前端契约 **72 项通过**，包括内部路由工具隐藏与真实查询工具保留，见 `frontend-contracts-run-01.txt`。
- 使用与工作区源码一致、没有私有环境文件的自有前端副本执行 Next.js 16.3.0 `next build --webpack`，包括 TypeScript 检查，通过。见 `frontend-build-01.txt`。保留既有 middleware 弃用及 Edge Runtime 兼容提示，不将其写成零警告。

### G0：受控模型及实际持久化 SDK

实际官方 LangGraph API、独立 PostgreSQL/Redis 和真实 Python SDK，身份、台账及数据为明确受控夹具。五轮“问候→缺半径→补齐并报告→报告后闲聊→改半径新修订”均通过；逐轮只有一条 done，保存的可见消息与实时终答的 ID 和正文一致。另一企业读取该线程返回拒绝。见 `browser-run-04/native-sdk.json`。

同一已完成运行再次 SDK join，公开消息 ID/正文摘要、checkpoint 和发布记录不变。join 与 checkpoint 的内部消息序列化不完全相等，已原样记录，不把内部差异当作公开正文不一致，也不声称原始状态逐字相等。见 `sdk-rejoin.json`、`sdk-rejoin-public.json`。同 attempt 幂等、重建 middleware、旧 epoch 拒绝、跨 scope 草稿拒绝及发布中断不换全文另有定向单测覆盖。

### G1：真实配置模型

使用当前配置的 `hy3` 主模型及实际 DeepAgents/LangGraph SDK；独立临时 SQLite checkpoint，站点、观测与网格为冻结 fixture，报告存储为本轮私有内存实例。身份复查和发布生命周期使用受控服务接缝，不访问正式 IAM、业务数据库或真实 MCP。

最终选取的 **34/34 次通过**：问候、能力边界、缺半径、补齐、完整分析、报告后闲聊、混合意图、恶意归因、非法半径、不存在站点、同名站点各三次，另一次模型生成后发布被拒绝。每次预期/实际路径、原因、模型/工具次数、数据读取次数、耗时、Token 与可见正文摘要保存在 `real-model-summary.json` 和关联原始 JSON。

普通交流每次一个模型调用，目录、污染/气象源、知识与专员外呼为零。完整分析和补齐后分析保留真实模型驱动的四专员与报告正向闭环。撤权反例为受控生命周期拒绝：真实模型生成一次，但没有 done、没有可见终答；不等同于真实 IAM 撤销联调。

最终选取样本累计 1018.667 秒；模型上报输入 358749、输出 103545 Token，包含专员调用。含被替换的首次回归，累计观测 1278.104 秒、输入 448214、输出 126467 Token（不含单次 smoke）。金额与实施总工时未采集，不记零。

首轮原始成绩 **26/29** 保留：一次完整分析因时间引用校验进入 fallback；两次报告后闲聊实际正确，但测试错误地用累计取数次数判断本轮是否取数。修复生产校验及测试按轮增量后，完整分析与报告后闲聊分别重跑三次均通过。没有覆盖旧文件或把原成绩改成通过。参见 `real-model-run-01.json`、`real-model-complete-rerun-02.json`、`real-model-duplicate-03.json`、`real-model-revoked-04.json`。

### G2：实际浏览器、BFF、页面与操作

使用真实 Next.js 页面、BFF 与自有官方运行服务，模型为固定刺激夹具，身份/台账为受控服务。完成问候、能力、缺半径、补齐、报告后闲聊及改半径。最终 20 公里请求为修订 3（首次受控台账缺失导致报告拒绝后有一次明确重试），历史报告未被闲聊覆盖。

- 同一浏览器线程的原生 API、BFF 六条可见消息 ID/正文摘要完全一致；页面 DOM ID 一致。
- 实际点击复制，再用系统 Meta+V 粘贴到输入框，复制正文与 BFF 完全一致；粘贴内容随后清空，未再次发送。
- 刷新并重开会话，六条正文与 DOM ID 全部一致。
- 390×844 窄屏下输入、Enter 发送、报告和停止可操作；根页面宽度/scrollWidth 均为 390。既有长英文报告字段有局部横向滚动，未在本次扩展为报告排版改造。
- 实际点击停止后，原生运行状态 `interrupted`；超过受控慢响应时长后仍无迟到终答。
- A→B→A 实际切换：B 页面零条 A 正文，BFF 读取 A 线程返回 404；回 A 后六条历史恢复。此处证明受控上下文下真实前端/BFF/native 过滤接线，不证明正式 IAM/RLS 租户验收。

证据：`browser-run-04/native-bff-page.json`、`page-bff-copy.json`、`history-layout.json`、`stopped-native.json`、`tenant-switch.json` 及同目录截图。未测试系统中文输入法组合事件、物理触屏或真实账号权限撤销，不将 Enter/剪贴板测试扩大解释为这些物理操作通过。

## 隔离资源与失败记录

- 自有容器仅 `aa-conversation-20261023-r02-*` 与 `aa-conversation-20261023-r04-*`；只读挂载源码，未发布 PostgreSQL 主机端口。自有服务端口 12625/18125/13125；未重建、seed、清空或迁移正式 15432 数据库，也未写入正式 IAM/Langfuse/MCP。
- 所有自有容器、前端临时副本及运行进程已回收，浏览器任务空间已关闭。见 `resource-cleanup-check.json` 与两次 `browser-stack-cleanup.json`。没有清理共享卷或镜像。
- 首次前端 Turbopack 不接受临时目录外的依赖符号链接，后改用 webpack；第二次在重载自有身份服务时触发父进程自动回收，第三次端口仍被占用、未启动资源，最终第 04 次完成验证。保留日志与空证据目录，不覆盖原失败。
- 第 04 次首个报告因受控台账未提供墓碑读取而失败关闭（`permission_revoked`）；补全测试台账读取后明确重试成功，没有改生产守卫。前一失败截图 `report.png` 与成功截图 `report-retry.png` 分开保留。
- 部分浏览器脚本因定位器歧义、缺少上下文头或跨 reload 等待失败；重新读取实际页面后继续。缺少上下文头的 BFF 读取被 403 拒绝，没有绕过检查。
- 原始测试服务日志以 gzip 无损保留，原字节数及 SHA256 见 `compressed-logs.json`。凭据环境文件只位于自有临时目录，未进入证据。
