## 逐次执行记录

每个 case、模式、重复次数和基线/新版分别留一条，真实模型核心语义链每条至少三次；多轮 case 每轮另行记录。不得只列成功样本。

- case ID、组、版本（旧/新）、重复序号、轮次及用户原文：
- 实际请求/受理/attempt/run/answer 关联（脱敏）及状态：
- 冻结时钟、目标城市/时间/指标/范围，实际领域工具稳定 ID、连接及完整脱敏参数断言：
- 目录、搜索及候选、选中、loaded（含缓存/材料版本/模式）、真实 executed 及工具结果状态：
- search 调用 / embedding 实际尝试 / load 尝试 / 领域真实请求及重试 / 模型实际发送 / 含工具调用批次；按轮次和干预前后分开：
- 每项允许/禁止行为和计数范围：预期、实际、PASS / FAIL / BLOCKED / NOT RUN；正控运行 ID 和计数：
- 数据与证据来源、对象/时间/单位/排名/引用检查、最终正文及人工语义判分：
- 首正文时间与总延迟、采集方式；usage、费用和覆盖率（不可得标未采集）：
- 原始输出、脱敏请求/响应、调用记录、截图或 trace 的证据链接；失败原因及限制：
