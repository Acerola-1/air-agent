## 已实现状态语义

`bqa_capabilities.version=2`保存本企业、用户、线程、图所属的Skill／工具加载引用和多个激活集合。`bqa_turn_key`及`bqa_turn_digest`仅区分attempt和冻结选择，正常新轮不清空能力，同attempt恢复拒绝换选择或静默换材料。旧单Skill记录只可从服务端原加载调用及成功回执迁移，普通历史文字和规则字符串不作为加载证明；迁移之后不再依赖历史回执仍在模型窗口中。

每次请求重新从Registry恢复全部活动规则，失败目标不清空其他能力。相同材料与模式返回`already_active`，休眠引用恢复为`activated`；回执不含规则正文。跨轮城市追问、复述／感谢、先A再B回A及多个加载部分失败已有受控编译图断言；正常追问没有新search/load和前置错误。
