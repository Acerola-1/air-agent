## 当前执行边界

- 删除 `_basic_qa_scope_denial`，执行路径不再调用 `current_material`、读取 Skill 工具归属、`load_ref`、`bqa_capabilities` 或激活状态判定资格；相关 Skill 专属拒绝码和强制重载提示同步删除。

- 没有 load 记录但本次定义与授权有效：可执行。仅激活状态变化：不额外拒绝已提出的有效调用。未提供给本次模型的工具、错消息／参数／schema：仍拒绝，不能靠猜名称执行。
