## 保持的契约与保留理由

- 公开 Graph ID 为 `basic-qa`；持久化节点ID仍为 `classify_intent`、`prepare_model`、`call_model`、`execute_tools`、`answer_model`、`ledger_finalize`。实现方法更名不等于持久化节点迁移。
- `intent` 继续使用 `data_query`／`input_overflow`，由常量说明其入口通过／输入超限语义；未新增 `input_status` 通道。
- `bqa_active_skill` 仍承担可证明的 v1 → v2 迁移输入；`user_id`、`skill_rules_content`、`needs_planning` 保留为旧通道，当前身份和业务路由不依赖这些值。
- `data_model_started_at` 是公共计算工具及数据分析也使用的计时契约。本轮仅将规划局部变量命名为 `planning_started_at`，不改单侧存储键。
- 工具包装入口及最低 MCP 工厂发送前的检查继续保留；搜索／加载不构成额外授权。
- 数据分析、溯源图、Skill 材料、业务策略版本、模型参数和正式环境未调整。公共 Skill 材料模块只修正职责注释。

本轮不采用直接删除旧状态通道或批量更名节点ID的建议；这些改动需要专门的历史检查点、在途运行和升级／回退证据，编译无法证明兼容。
