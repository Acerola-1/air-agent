## 修复

每次模型请求明确当前加载状态。上一轮的成功回执只在模型投影中改为 `historical_load`，不改写原始执行历史；当前完整规则仍由活动材料重建。

工具执行入口区分可恢复的前置条件和真实授权错误：

- `skill_not_loaded`：本轮尚未加载，提示先单独 `load_skill` 再继续原查询。
- `skill_tool_mismatch`：当前 Skill 工具不匹配，提示加载合适 Skill。
- `skill_reload_required`：加载记录失效，提示按当前目录重新加载。
- 身份/业务拒绝继续抛出，不转成重载提示；真实工具授权403仍按原策略停止。

上述加载前置条件使用409，不永久耗尽原查询工具。工具仍需经过有效加载及原有业务/连接/受理范围检查才会真正发送；没有放开未加载的领域外呼。搜索仍然可选：已知基础查询 Skill 可直接加载，只有选择不确定时才需搜索。
