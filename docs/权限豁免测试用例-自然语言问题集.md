# 权限豁免手工测试用例

本文档用于人工端到端测试 AI 智能问数权限链路。每条用例都给出可直接复制的问题、要验证的规则点、期望权限结果和最终查询应使用的区域/时间。

### 时间说明

手工测试时建议优先使用绝对日期，避免“昨天”“上月”等相对时间随测试日期变化。

本文默认按当前运行日期 `2026-06-04` 理解相对时间：

| 粒度 | 豁免窗口 |
| --- | --- |
| 小时 / 日累计 / 日 / 自定义时间段 | `2026-05-29` 至 `2026-06-04` |
| 月 / 月累计 | `2026-05` 至 `2026-06` |
| 年 / 年累计 | `2025` 至 `2026` |

如果实际测试日期不是 `2026-06-04`，相对时间窗口需要随测试当天平移。

### 期望结果字段说明

| 期望类型 | 应重点观察 |
| --- | --- |
| `no_check` | 不应进入权限审查，不应调用权限 MCP。 |
| `auto_fill` | 用户未指定行政区；应跳过 `resolve_region_scope`；使用 `bound_region`；`auto_filled=true`；回复说明“已自动补全查询区域”。 |
| `full_window` | 时间完全在豁免窗口内；`permitted=true`；`exemption=full_window`；不修正行政区。 |
| `normal_allow` | 不命中时间豁免，但基础行政区权限允许；`permitted=true`；`exemption=normal`。 |
| `truncate_time` | 时间范围和豁免窗口部分相交；`fix_strategy=truncate_time`；查询时间改成合法交集；行政区保留原请求。 |
| `replace_region` | 无时间豁免且行政区越权；`fix_strategy=replace_region`；查询区域改成 `期望查询区域`。 |
| `reject` | 权限事实不足或无法安全修正；应拒绝查询。 |

| MR-08 | `U-CITY-SQ` | 郑州市金水区和平顶山市卫东区空气质量分别怎么样？ | 多区县独立消歧 | `multi_explicit` | 每个区县项带独立 `city_hint` 并逐项解析 | 不应把两个区县都按用户绑定城市消歧 |

| MR-10 | `U-CITY-SQ` | 昨天空气质量如何？ | 自动补全逐项来源 | `auto_fill` | `region_results[0].requested.source = auto_fill` | 不应把自动补全误标为用户显式输入 |
