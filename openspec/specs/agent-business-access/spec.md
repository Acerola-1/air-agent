# agent-business-access Specification

## Purpose

使 Agent 以稳定业务作为人员使用资格的唯一普通授权对象，消费 IAM 当前企业下的有效权限，在目录、受理、真实图执行和运行中使用一致规则，同时保留会话、租户、台账及删除边界。

## Requirements


### Requirement: 稳定业务目录与可信执行映射
系统 SHALL 为每个公开业务维护稳定编码、中文名、使用权限和 Graph 映射，实际运行从可信平台目标解析业务。未登记、停用或映射冲突的图 MUST 拒绝运行，客户端业务声明不构成依据。

#### Scenario: 改名或新增图
- **WHEN** 业务更换内部图或增加新业务图
- **THEN** 既有业务授权不因内部路径变化失效；新业务未登记开通与授权前不可运行

#### Scenario: 借已获准业务启动另一图
- **WHEN** 请求声明基础问答但实际 assistant 对应未获准的溯源图
- **THEN** 执行前拒绝，溯源模型和工具新增请求数均为0

### Requirement: IAM 实时业务资格
系统 SHALL 只根据当前有效 IAM 身份的业务使用权限判断资格，要求账号、企业、成员及上下文有效。普通 Skill/MCP 不再要求人员独立授权；平台管理员和 root MUST 使用相同准入规则。

#### Scenario: 企业开通但角色未授
- **WHEN** 企业已开通分析业务但本人本企业角色未获使用权限
- **THEN** 分析入口不可运行，直接 API 返回403；合法已授用户作为正对照成功

#### Scenario: 同账号跨企业
- **WHEN** 用户在A获分析权限，在B仅获问答权限
- **THEN** A角色不能使B的分析业务可用，切换后旧上下文不能沿用

### Requirement: 全入口受理和恢复检查
目录、台账受理、原生 stream/wait、BFF、重新生成及恢复 SHALL 检查同一业务权限。服务端受理记录 MUST 固定业务、实际图与策略版本，不接受前端替换；已有幂等、所有权和删除规则继续生效。

#### Scenario: 绕过聊天页面直连
- **WHEN** 无业务资格者直接请求原生运行或伪造已受理业务字段
- **THEN** 在启动外部调用前拒绝，不产生获准运行；有资格的原生与BFF运行均成功

#### Scenario: 删除或撤权后恢复
- **WHEN** 暂停运行后业务权限被撤销或线程已删除，再提交恢复
- **THEN** 恢复拒绝，不复活旧许可、选择或已删除内容

### Requirement: 每次发送前复查及内部委派
模型、MCP、辅助模型、重试及子任务发送前 SHALL 重新确认身份与所属业务仍可执行。内部子任务继承父业务上下文和执行范围，不因委派获得另一独立业务；合法内部协作无需额外授予用户子任务实现名。

#### Scenario: 长运行中回收
- **WHEN** 首次调用成功后企业回收业务或角色撤权
- **THEN** 提交后的下一次受保护发送被拒绝，真实网络增量为0；已发送请求不宣称可撤回

#### Scenario: 子任务替换业务
- **WHEN** 子任务伪造另一已部署Graph以扩大业务资格
- **THEN** 不改变父业务绑定，跨独立业务调用须另获目标业务资格或拒绝

### Requirement: 失败关闭与可解释状态
未登录、业务无权、上下文冲突及 IAM 故障 SHALL 分别保留401、403、409、503语义；不使用跨请求正向权限缓存、旧本地身份或匿名身份兜底。前端 SHALL 以中文区分业务未开通、未授权、停用与连接故障。

#### Scenario: 已成功后 IAM 故障
- **WHEN** 用户刚运行成功，随后IAM超时或返回非法身份协议
- **THEN** 新运行及后续发送失败关闭，不从最近成功响应放行

### Requirement: root 实际测试权限与数据边界
交付 SHALL 通过配套 IAM 显式配置现有 root 的当前业务权限，并验证各企业上下文内业务运行和获准 Agent 数据查看。历史记录读取继续采用所有权或独立运营权限，不能把业务使用权当作查看其他用户正文的资格。

#### Scenario: root 全业务和运营查看
- **WHEN** root 重新登录并切换至已完成配置的有效企业
- **THEN** 当前注册三项业务可受理运行，业务数据按其已授运营/原文权限可查看，全部操作可审计

#### Scenario: 普通成员运行与读他人记录
- **WHEN** 普通成员可使用分析业务但未获运营或原文读取权限
- **THEN** 能运行自己的分析，但不能读取他人受控正文，root配置不扩大其他成员权限

### Requirement: 已有数据和异步界面隔离
业务授权变更 SHALL 保持 FORCE RLS、非owner请求角色、可信事务上下文、同租户关联及删除优先。停止、本人删除等安全收尾动作不要求继续拥有已撤回的业务使用资格；迟到响应按用户、企业、图及上下文代次丢弃。

#### Scenario: 业务被回收后的收尾
- **WHEN** 企业业务回收，原用户尝试停止仍在运行的本人任务或删除本人会话
- **THEN** 身份仍有效且满足原有收尾权限时允许操作，但不能借此恢复或新建运行
