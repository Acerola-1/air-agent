# agent-observability-access Specification

## Purpose

向本人、企业运营和统计角色提供有界、分级授权的模型与能力观测查询，并验证Langfuse真实落库与业务台账的一致映射。保护跨企业数据、原文和服务凭据，保证删除、故障与历史未采集数据都具有明确可解释状态。

## Requirements

### Requirement: 分级授权与数据库隔离
系统 SHALL 以可信身份和非owner数据库角色读取观测，强制租户RLS及同企业关联。本人回读仅限本人运行；运营明细需要运营权限，汇总需要统计权限，价格修改另需配置权限；平台账号不隐式拥有企业原文或Trace权限。

#### Scenario: 同用户加入两企业
- **WHEN** 同一用户在企业A和B产生同名工具/模型记录，当前企业为A
- **THEN** 查询、缓存及游标只返回A范围，切换后清除A可见缓存

#### Scenario: 连接池复用
- **WHEN** 非owner连接依次处理A、B及无租户上下文事务
- **THEN** 各自只能读取所属记录，无上下文不能读取任何企业记录

### Requirement: Langfuse实测与窄范围查询
系统 SHALL 使用已安装SDK及Langfuse支持接口验证真实Trace/observation落库，并按业务attempt与主/辅助Trace保存映射。企业查询经过可信服务核验租户、运行归属及所需权限，不向浏览器暴露密钥或共享项目访问凭据；共享项目不提供绕过租户核验的控制台直链。

#### Scenario: 回调已绑定但未落库
- **WHEN** 回调执行而Langfuse写入或查询未成功
- **THEN** 标为未确认同步，不能报告真实Trace已落库或100%覆盖

#### Scenario: 伪造Trace标识
- **WHEN** 企业A运营用户用企业B的Trace标识查询
- **THEN** 在调用Langfuse查询前拒绝，响应不暴露B的记录或存在性

### Requirement: Langfuse完整采集和删除优先
系统 SHALL 在启用 Langfuse 时完整记录 SDK 获得的图与节点输入输出、系统提示与对话、模型响应、工具定义及参数结果、元数据与实际异常；MUST NOT 通过统一正文 mask、OTel 白名单或异常跨度丢弃把内容清空、截断或替换为固定错误文本。普通业务事件、统计台账和本地日志继续采用各自的安全字段规则；Langfuse 完整采集不扩大产品查询权限。删除标记优先于晚到回调、同步和重放；本地立即禁读，外部删除有界重试并报告待清理状态，不能恢复已删原文或伪造外部删除成功。

#### Scenario: 查看完整运行内容
- **WHEN** 已启用 Langfuse 的图执行模型与工具调用
- **THEN** Langfuse 中可查看 SDK 实际收到的完整输入、输出与异常，且模型、工具与节点的父子关联保持完整
- **AND** SDK 单例先由提示词查询初始化时，后续观测仍不得沿用旧正文过滤器

#### Scenario: 删除时晚到回调
- **WHEN** 线程删除后收到usage或Langfuse同步回调
- **THEN** 不恢复可识别运行明细或原文，不创建新的外部含正文Trace

#### Scenario: 外部删除服务故障
- **WHEN** 本地已禁止读取而Langfuse删除暂时失败
- **THEN** 保留外部清理待处理标记并有界重试，本地访问继续拒绝

### Requirement: 真实聚合与有界分页
系统 SHALL 提供按授权用户、Graph、Skill、工具服务/工具、模型、版本及时间范围筛选的观测与聚合，包含明细可核对的分子分母、样本/缺失、截止时间、采集来源和版本。分页最多200条，游标绑定查询与租户，分位数由有效明细计算，未接入数据不返回伪零。

#### Scenario: usage与工具统计核对
- **WHEN** 确定性样本包含重复回调、重试、业务无结果和缺失usage
- **THEN** 汇总与去重后的逐调用明细一致，失败类别、覆盖率和缺失可分别核对

### Requirement: 性能与故障证据分开
系统 SHALL 记录观测开启前后在相同本地输入、资源与并发下的增量开销、样本数、队列丢弃和数据库查询量，分别报告外部模型/Langfuse等待。实测、测试替身、历史材料与未知必须分开，不能用测试执行耗时冒充应用P95。

#### Scenario: 性能复测
- **WHEN** 使用至少30次相同受控调用比较关闭/开启观测
- **THEN** 报告本地P50/P95增量、样本与条件；本地新增P95超过50ms时查明并修复或明确留作待验收问题
