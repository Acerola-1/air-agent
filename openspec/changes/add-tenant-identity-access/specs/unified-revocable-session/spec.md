# 统一身份与可撤销会话

## Purpose

让聊天前端、管理前端和 Agent 使用同一个可信登录主体与企业成员上下文，支持会话撤销和企业切换，防止兼容 cookie、浏览器缓存或客户端自报身份绕过当前企业授权状态。

## ADDED Requirements

### Requirement: 唯一认证来源与历史会话切换

系统 SHALL 使用统一持久化身份源认证两个前端，切换后停止线上 JSON 账号写入和公开自助注册；旧无撤销能力的会话 MUST 被拒绝并引导重新登录。

#### Scenario: 两个前端登录同一账号
- **WHEN** 用户分别通过聊天端和后台认证
- **THEN** 两者得到相同全局用户身份，企业权限从同一有效成员关系获取
- **AND** 密码哈希和内部身份凭据不返回浏览器

#### Scenario: 旧 cookie 或旧注册入口
- **WHEN** 客户端使用旧 HMAC cookie 或调用旧公开注册接口
- **THEN** 系统不授予企业访问，提示重新登录或管理员开通流程

### Requirement: 服务器可撤销会话

系统 SHALL 将会话有效性与当前用户、企业和成员状态实时核对；登出、密码变更、账号停用或会话撤销后，后续请求 MUST 不因浏览器仍有旧 cookie 而获得访问。

#### Scenario: 登出后重放 cookie
- **WHEN** 已登出客户端重放先前有效 cookie
- **THEN** 所有认证业务请求返回未认证，无法访问聊天或管理资源

#### Scenario: 全局密码修改
- **WHEN** 用户密码被有权主体修改
- **THEN** 按会话策略撤销既有会话，已登录页面的后续业务请求不再成功

### Requirement: 当前企业由可信成员关系选择

系统 SHALL 只允许用户选择其有效成员所属的有效企业；多企业且未选择时不得自动使用第一家企业，任何目标企业输入都必须与服务器会话上下文匹配。

#### Scenario: 多企业首次登录
- **WHEN** 用户有 A/B 两个成员身份但无当前企业
- **THEN** 系统展示可选择企业，选择前不提交企业业务请求

#### Scenario: 未授权企业选择
- **WHEN** 用户指定未加入企业 C
- **THEN** 系统拒绝，保持原会话上下文，不返回 C 的成员或业务信息

### Requirement: 企业切换与旧页面请求隔离

系统 SHALL 明确处理活动运行后再切换企业，并使旧页面请求和多标签页缓存失效；旧企业页面提交不得被静默写入新企业。

#### Scenario: 回答中切换企业
- **WHEN** 用户在 A 的回答进行中请求切换 B
- **THEN** 系统请求停止并确认后切换，清除旧线程、归档和列表的可见缓存
- **AND** 停止未确认时显示明确状态，不宣称已完成切换

#### Scenario: 旧标签页继续提交
- **WHEN** 当前企业已从 A 切换 B，旧标签页仍以 A 的上下文提交
- **THEN** 请求因上下文冲突被拒绝并要求刷新，不能在 B 新建该请求

#### Scenario: 切换回原企业
- **WHEN** 用户重新选择仍有权访问的 A
- **THEN** A 的既有本人资源可以恢复读取，B 内容不残留在当前界面

### Requirement: 运行上下文不可由客户端伪造

系统 SHALL 在 Agent 入站认证后提供可信租户、用户、成员及会话标识，覆盖或拒绝客户端在 metadata、config、input 或 header 中伪造的身份；运行认证票据 MUST 限定受众、时效与签发来源。

#### Scenario: 伪造运行身份
- **WHEN** A 用户在运行输入或配置中填写 B 租户/用户/成员
- **THEN** 系统拒绝或强制使用 A 的真实身份，不以伪造字段查询或调用工具

#### Scenario: 错误受众或过期票据
- **WHEN** 服务票据过期、被篡改或受众不符
- **THEN** Agent 拒绝请求，普通 API key 不替代企业成员认证

### Requirement: 跨站写入与依赖故障处理

系统 SHALL 校验基于 cookie 的业务写操作来源或等价 CSRF 证明；认证依赖不可用时必须拒绝访问并返回可读不可用状态，不降级为匿名或本地旧身份。

#### Scenario: 跨站企业切换
- **WHEN** 未授权来源使用浏览器 cookie 请求切换企业或修改成员
- **THEN** 请求被拒绝且会话/成员状态保持

#### Scenario: 身份服务或数据库不可用
- **WHEN** 系统无法确认当前授权
- **THEN** 请求返回服务不可用，不能继续向模型或 MCP 发起新业务调用

### Requirement: 身份验证不公开传输凭据

系统 SHALL 仅向浏览器和可回读运行记录公开必要身份与授权状态；会话原始 token、内部运行票据、密码哈希和外部业务凭据 MUST 不进入响应详情、持久化对话或 Trace。

#### Scenario: 读取运行状态与诊断
- **WHEN** 用户读取状态、历史、归档或展开错误诊断
- **THEN** 内容不包含认证传输票据、凭据或密码哈希
