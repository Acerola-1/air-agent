# 企业资源端到端隔离

## Purpose

为多企业共用的 Agent 执行与资料存储建立一致的资源归属和访问边界，使内置线程接口、自定义归档接口、运行恢复和计算路径都遵循可信企业身份，不因直连服务或并发复用产生跨企业访问。

## ADDED Requirements

### Requirement: 企业资源具有可信归属

系统 SHALL 为每个新企业线程、运行和归档绑定可信企业与所有者，创建和更新时不得由客户端指定或修改归属；普通成员仅访问当前企业本人的线程。

#### Scenario: 线程创建和 metadata 修改
- **WHEN** A 用户创建线程或更新其 metadata 并提交其他所有者
- **THEN** 归属保持可信 A/本人身份，不能将线程转移到其他企业或用户

#### Scenario: 同一用户属于两企业
- **WHEN** 同一全局用户在 B 上下文请求读取其 A 线程
- **THEN** 请求被拒绝，不能仅按相同 user_id 放行

### Requirement: 原生资源接口授权一致

系统 SHALL 在线程搜索/计数/详情/状态/历史/更新/删除和运行创建/列表/详情/流式/join/cancel/resume 上执行相同归属校验，不得仅保护浏览器使用的常见端点。

#### Scenario: 跨企业搜索与计数
- **WHEN** A 用户改变过滤、分页或请求 count
- **THEN** 可见资源与数量仅包含其 A 授权范围，B 数据不进入返回结果

#### Scenario: 取消或恢复其他企业运行
- **WHEN** A 用户提供 B 的 run/thread 标识请求 join、cancel 或 resume
- **THEN** 请求被拒绝，不改变 B 的执行状态

#### Scenario: 删除自己的线程
- **WHEN** A 用户删除本人 A 线程
- **THEN** 相关原始/派生归档按既有契约清理，不影响 B 或 A 的其他用户

### Requirement: 直接访问和辅助资源不形成旁路

系统 SHALL 在 Agent 服务直接访问与自定义归档接口校验可信企业认证；未授权的 assistant 写入、批量运行、定时任务与任意存储命名空间操作必须拒绝，公开助手发现限于当前授权能力。

#### Scenario: 绕过聊天代理
- **WHEN** 客户端直接请求 Agent 服务而无可信企业认证
- **THEN** 请求被拒绝，noop 配置或普通平台 API key 不授予成员数据访问

#### Scenario: 平台辅助入口
- **WHEN** 成员尝试通过批量、cron 或任意 store namespace 访问未授权资源
- **THEN** 系统拒绝，不能绕过线程/企业归属

#### Scenario: 自定义归档地址
- **WHEN** 调用者直接访问归档地址或重放其他企业 scope
- **THEN** 系统拒绝，不返回归档摘要、页内容或内部处理元数据

### Requirement: 六个图采用相同身份边界

系统 SHALL 对全部公开图采用统一入站身份和执行授权，模型/工具披露按权限收敛；运行中当前授权失效后不得再发起新的模型或工具调用。

#### Scenario: 六图跨租户运行
- **WHEN** 授权成员逐个运行六个公开图，并尝试用 B 的上下文或资源
- **THEN** 合法运行使用本人当前企业，所有越权路径被拒绝
- **AND** 不因显式图和其他图执行机制不同而放宽授权

#### Scenario: 运行中成员停用
- **WHEN** 已开始运行的成员被停用，随后运行准备下一次调用
- **THEN** 新调用被拒绝，返回可读权限变化状态

### Requirement: 归档回读与计算完整隔离

系统 SHALL 对原始/派生归档的保存、列表、分页、更新、回读、计算和删除同时校验企业、用户与线程归属；必须保持原有完整数据、失败不虚报归档成功及过期规则。

#### Scenario: 混合企业计算引用
- **WHEN** 当前 A 计算引用了 A 和 B 的归档
- **THEN** 计算不读取 B 数据，不返回混合结果

#### Scenario: 归档过期或存储失败
- **WHEN** 本人 A 资料过期或可靠写入失败
- **THEN** 继续按既有规则返回明确过期/失败，不用其他企业数据补齐结果

### Requirement: 自有数据库租户边界可靠

系统 SHALL 对自有租户表实施数据库访问约束和可信事务作用域；缺少上下文、跨租户外键关联和连接复用造成的残留上下文必须被拒绝或清除，运行角色不得绕过隔离。

#### Scenario: 非所有者角色越界查询
- **WHEN** 运行数据库角色在 A 作用域查询或写入 B 行
- **THEN** 查询不可见或写入被拒绝，不能依赖调用者自行添加 WHERE

#### Scenario: 连接池交错与失败回收
- **WHEN** A/B 请求交错复用连接，A 请求发生异常或取消
- **THEN** B 的后续事务只见 B 授权数据，缺失作用域的事务不能沿用 A

### Requirement: 未知历史归属与维护角色受限

系统 SHALL 对未能验证租户归属的历史资源保持不可访问；维护和平台管理路径必须显式限定权限、记录审计，不能自动获得所有企业原始对话读取权。

#### Scenario: 旧线程或归档没有企业
- **WHEN** 成员请求未完成可信迁移的历史对象
- **THEN** 系统不默认分配当前企业，也不仅按相同用户名/用户 ID 放行

#### Scenario: 过期清理或平台管理
- **WHEN** 维护角色清理到期资料或平台管理员管理企业
- **THEN** 只执行明确授权操作，不获得任意原始对话回读能力
