## Purpose

让基础问答在同一线程内理解连续追问、话题切换和已有结果复述，按需发现与加载业务 Skill。使规则、工具及证据的使用有明确的生命周期与失败行为，在提高多轮自然性的同时保持既有身份、业务范围和会话隔离。

## ADDED Requirements

### Requirement: 基于会话上下文决策
Basic QA SHALL 在决定是否搜索、加载 Skill 或调用工具前，为模型提供当前真实用户消息、可用历史及有效摘要、当前模式和本图 Skill 简介。系统 MUST NOT 仅凭最新一句的关键词或向量 top1 锁定业务能力；信息不足时 SHALL 澄清，不猜测缺失城市、日期或指标。

#### Scenario: 延续城市追问
- **WHEN** 同一线程先询问“湖州市今天的空气质量如何”，随后发送“那杭州呢？”
- **THEN** 模型能以本轮时间和历史确定杭州空气质量查询任务；工具参数使用杭州，不把上一轮湖州结果作为杭州数据

#### Scenario: 无历史的省略问题
- **WHEN** 新线程只收到“那杭州呢？”
- **THEN** 请求补充查询内容，不凭空确定是空气质量、天气或其他问题

#### Scenario: 话题切换和知识追问
- **WHEN** 数据查询后用户改问环保概念、说“谢谢”或要求“把刚才的结论缩成两句”
- **THEN** 根据本轮与历史决定知识回答、寒暄或复述，不因上一轮 Skill 自动执行领域数据查询；具体法规依据仍遵循知识引用要求

### Requirement: 可选 Skill 搜索
系统 SHALL 提供由模型按需调用的 `search_skills(query)`，以模型结合上下文构造的查询进行语义检索，仅返回本次业务与选择范围内的稳定 Skill ID、简介、材料版本及匹配信息。搜索 MUST NOT 自动加载 top1 或执行业务工具；已知 Skill SHALL 支持跳过搜索直接加载。搜索的 embedding 外呼 SHALL 受实时身份和业务守卫保护。

#### Scenario: 上下文检索
- **WHEN** 模型对城市追问调用搜索
- **THEN** 检索输入包含可解释的完整业务需求而非系统机械截取最新四字；返回候选仍需模型决定是否加载

#### Scenario: 不需要搜索
- **WHEN** 本轮可直接从目录或已知 Skill 引用确定需要加载的 Skill，或仅需寒暄/复述
- **THEN** 允许本轮零搜索、零 embedding；不得为填充观测而伪造匹配事件

#### Scenario: 搜索失败或无命中
- **WHEN** 搜索超时或没有适合候选
- **THEN** 模型可基于有效目录直接加载、澄清或说明能力不足；不得自动开放全量领域工具或无限重复搜索

### Requirement: 可信加载及工具披露
系统 SHALL 提供 `load_skill`，校验 Skill 所属图、稳定 ID、材料版本、运行模式、已受理选择及当前业务资格，成功后加载总纲与模式规则并激活其可用工具。加载 MUST NOT 创建人员权限或执行查询。业务工具 SHALL 同时满足系统业务范围、连接与查询白名单、已受理工具选择及活动 Skill 范围。

#### Scenario: 直接加载已知 Skill
- **WHEN** 模型未搜索但使用目录中的有效 ID 和版本加载 Skill
- **THEN** 加载成功，下一次模型请求包含完整有效规则及相应工具；加载动作的业务数据请求数为0

#### Scenario: 非法或失效加载
- **WHEN** 加载跨图 ID、伪造路径、旧版本、缺失材料、缺失必需依赖或与显式选择冲突的 Skill
- **THEN** 返回可识别失败，不激活目标、不回退到全部工具；不能借旧活动规则继续执行新任务

### Requirement: 本轮活动状态与线程缓存分离
系统 SHALL 在每个新的用户业务轮次清空活动 Skill，保留可验证的历史材料引用供模型直接加载复用。首版同一时刻 SHALL 只激活一个 Skill；自动模式顺序加载另一 Skill 后替换当前规则与工具，历史证据仍保留来源。显式选择 MUST NOT 被模型替换。缓存和旧消息 MUST NOT 作为本轮加载或授权证明。

#### Scenario: 同 Skill 的第二轮
- **WHEN** 杭州追问与湖州上一轮使用同一 Skill 且材料未变
- **THEN** 可直接加载缓存材料以激活本轮 Skill，无需重新搜索；缓存命中仍重新校验版本、身份和已受理范围

#### Scenario: 历史加载不混淆本轮状态
- **WHEN** 新轮清空活动 Skill 而历史包含上轮成功加载回执
- **THEN** 模型明确获知本轮尚未加载，历史回执在模型投影中标为历史记录；原始执行历史保持不变

#### Scenario: 漏加载后继续原查询
- **WHEN** 模型未在本轮加载便沿用历史中的领域工具名
- **THEN** 不发生领域外呼，返回可识别的先加载说明而不是人员授权拒绝；模型可补加载后重新调用原工具，该前置条件错误不永久耗尽工具；实际身份或业务撤权仍停止执行

#### Scenario: 换 Skill 后旧工具调用
- **WHEN** 自动模式从 S1 切换 S2 后模型使用旧 S1 专属工具
- **THEN** 调用被拒绝，除非该工具也在当前 S2 的有效范围内；不合并两个 Skill 的工具并集

#### Scenario: 切换失败
- **WHEN** S1 活动时尝试切换 S2，但 S2 加载失败
- **THEN** 清空活动执行状态，保留带来源的历史证据；必须重新成功加载后才能继续领域工具调用

### Requirement: 工具执行顺序及真实边界
领域数据工具 SHALL 仅在本轮 Skill 加载成功并经模型读取新规则后的后续调用中执行。执行入口 MUST 再次校验实时业务、选择、活动材料及工具范围；仅隐藏 schema 不构成保护。通用工具 SHALL 有明确分类，不能作为未加载时绕过领域数据门禁的通道。

#### Scenario: 同批加载与查询
- **WHEN** 模型在同一批工具调用中混合加载与领域查询，或同时加载两个 Skill
- **THEN** 拒绝该批有冲突的控制与领域调用，领域实际外呼为0；返回顺序纠正信息，要求先单独加载再决策

#### Scenario: 直接伪造业务工具调用
- **WHEN** 未加载、已失效或旧 schema 中的领域工具被直接调用
- **THEN** 真实工具入口拒绝，领域外部请求为0；合法加载后相同工具的正向用例能够成功

#### Scenario: 执行前撤权或取消
- **WHEN** 加载后用户业务资格失效、IAM不可用、运行取消或线程删除
- **THEN** 按既有守卫停止后续模型、embedding和工具发送，不通过缓存或重试继续

### Requirement: 逐次发送和恢复的规则一致性
每次规划、工具后续、终答及必要的清理模型请求 SHALL 使用当前有效规则并计入完整上下文预算。摘要不得替代活动 Skill 的权威规则。恢复 SHALL 重查原受理范围及已加载版本；旧线程缺少新状态时默认未加载，不从历史字符串反推执行资格。

#### Scenario: 规则消息已被整理
- **WHEN** 工具循环触发上下文整理，历史加载返回已被摘要覆盖
- **THEN** 后续发送仍含当前完整有效规则和正确工具范围；不能容纳时受控结束，不静默截断规则

#### Scenario: 恢复时材料变化
- **WHEN** 中断运行恢复时活动 Skill 材料版本已改变
- **THEN** 拒绝沿用旧执行状态，要求新提交，不在同一 attempt 中静默替换材料版本

#### Scenario: 旧会话继续
- **WHEN** 升级前会话带有旧规则字符串但没有新活动状态
- **THEN** 历史可供理解，本轮领域工具仍需重新加载；旧规则字符串不重新激活工具

### Requirement: 有界循环与自然结束
系统 SHALL 对循环和重复无进展行为设置有限预算。模型没有后续工具调用或调用无参结束信号时 SHALL 进入既有终答阶段，保留有效历史、摘要和工具结果。系统 MUST NOT 新增接口回显城市/时间/指标、回答分类或证据引用的服务端校验来拦截回答；现有身份、业务工具范围、知识引用及流式发布规则继续适用。

#### Scenario: 从现状转问原因
- **WHEN** 查询杭州空气质量后追问“可能的原因是什么”
- **THEN** 重新评估现有 Skill 边界；可用已有气象证据作有局限解释，或说明需溯源分析；不得把基础查询包装成已验证污染来源，也不得自动跨图启动任务

#### Scenario: 循环无进展
- **WHEN** 连续重复相同失败的搜索、加载或工具请求达到预算
- **THEN** 停止追加调用，说明未获得的信息及可行下一步，正常结束台账；不得伪造成功或持续循环

### Requirement: 固定多轮验收证据
本能力 SHALL 使用版本化固定多轮用例，并分别记录受控模型、真实配置模型、持久化原生运行及浏览器结果。报告 SHALL 包含搜索/加载/外呼次数、实际调用参数断言、规则与证据版本、延迟及可用 usage；缺失结果标为未采集或阻塞，不能用结构校验替代产品验收。

#### Scenario: 同一组用例前后对比
- **WHEN** 验证本变更的多轮行为
- **THEN** 使用相同问题和数据口径对比旧版及新版，覆盖追问、话题切换、加载失败、恢复及越界反例；保留原始失败，不只展示成功案例

#### Scenario: 接口不回显查询参数
- **WHEN** 已获准工具返回结果但没有回显查询城市或时间，或返回文本而非预设 JSON 结构
- **THEN** 结果正常提供给模型结合 Skill、调用参数和会话上下文组织回答，不因上述字段缺失阻断终答

#### Scenario: 普通解释后的复述
- **WHEN** 用户要求把上一轮知识解释或业务回答缩写
- **THEN** 终答模型能看到对应历史及有效摘要，无需额外声明回答类别、城市、时间或证据 ID
