# Design

## Context

动机见 proposal。当前 HEAD 为 `0b3c4bf`，有此前溯源路由、SSO 和其他性能任务的未提交改动；本变更只增量修改本域数据/计算/发布门禁及定向测试。无 `.codegraph/`，不建立索引。主规格 `agent-business-access` 与 `agent-service-connections` 已完整核对；溯源、会话路由、统一流式等仍有活动 change，不能把文档复核当实施验收。

用户已确认当前只有业务 MCP，没有观测气象/CEMS/ERA5/FIRMS 的额外授权渠道。代码中有效产品映射仅站点目录/小时浓度、历史模式气象、网格浓度与几何。已审核业务工具清单没有据此证明可用的 CEMS 或气象观测渠道；禁止猜造工具名或绕过连接白名单。当前轨迹/PSCF 在业务注册及执行层双重禁用。

已观察：`_station_series` 固定使用分析窗口；`baseline_statistics` 从 observations 筛基线；`evaluate_request` 只看到目标已清洗时段；峰值/变化依赖异常；空间不足被写成 no_target_anomaly；气象 schema 有起报/时效但归一化不填；网格按各点跨时峰值拼接并以 0.01 度猜拓扑，邻站按目录顺序截断。先修这些明确缺陷，再谈外部数据覆盖。

## Goals / Non-Goals

**Goals:** 四步都具备明确交付与验收条件；当前可执行的首批完成站点时窗、独立事实、状态区分、现有模式时效和同刻网格修复，建立固定样本和原案例真实复验的证据路径。

**Non-Goals:** 不推断法规新限值、不以插值补齐监测值、不自动扩大半径或跨城市，不注册账户/接受数据许可，不购买服务、不保存浏览器提供的地址或凭据。不启用旧轨迹/PSCF，不用公开网页爬取冒充稳定授权接口，不扩展贡献率或企业因果确认。未配置渠道只能写未完成，不把本计划称为已接通全部数据。

## Decisions

### 1. 独立数据用途与窗口

新增确定性窗口规划，目标为冻结分析窗口，基线沿用显式基线或七天默认；PM2.5 滑动统计最多取前 23 小时，O3 最多取前 7 小时，其他无已定义滑动指标不取补充时段。辅助窗口按重叠/相邻合并，分离窗口不读取无用途的间隔；目标与辅助分开查询，避免基线失败吞掉目标。先校验窗口和最大样本预算，再使用已有执行器逐次复查资格。

DataBundle 增加显式可选基线与前置序列；旧 fixture/checkpoint 缺字段时从旧 observations 按用途筛选，显式空集合表示确实缺数，不能隐式回填。站点结果、基线及滑动统计独立清洗和覆盖；辅助系列、缺失与来源要可追踪。目标统计严格排除辅助小时。评价只输出请求范围内的归属日期/窗口，指标口径保持，不把已有 18/24 等有效性策略换成任意补值。

不采用一次拼成长范围查询的方案：非相邻基线可能造成不必要读取；一次历史失败也会使目标事实丢失。对受理选择、身份、范围和上游鉴权错误不得通过“可选基线失败”降级放行；只有非授权的产品不可用可以作为局部缺口。

### 2. 基础事实从异常结论分离

保留目标 quality 与 baseline 两类状态。峰值、均值/最低值、有效样本首末变化仅依赖合格 station_series；异常出现/持续、相对变化和来源解释仍依赖各自证据。新增或调整的 claim 必须有类型化参数、可信引用与确定性渲染；保持无原始模型正文旁路。

不足状态传播为 target_anomaly_unknown，无异常保留 no_target_anomaly。首批不在缺分段时制造同步判断，但可以呈现独立天气背景。检出异常的旧主路径、组合传输条件和必需限制继续有效。

### 3. 现有空间与气象产品修复

邻站在冻结半径内按实际球面距离和稳定代码排序后有界读取，记录截断和缺数。网格按有效时间选取同刻快照，半径筛选和样本截断有标记；几何只接纳明确的行列/拓扑，未知时保留点位并停止连通推断，不能用经纬度固定步长补造。样本快照不能代表整个过程或全区无热点。

现有气象仅声明历史模式来源，保留上游明确提供的 run_time/lead_hours、有效时间；两者矛盾时记录质量问题，绝不推断为新观测。现有 schema/产品未确认的字段不任意映射；单位/时区按具体接口契约处理。补充真实观测或 ERA5 必须走独立适配和真实渠道验收，不替换当前字段标签来消除限制。

### 4. 后续排放源产品

先建立授权渠道、schema、字段样本、站点/企业/排口坐标与时间覆盖登记，再实现接口；候选源只来自核验后的数据，CEMS/工况与许可/年度清单分开。来源核查记录支持、反证、时间重叠和待核查状态，仍不输出具体因果或贡献。现有 MCP 若无此能力，任务保留未完成，不能新增一个只返回空数组的适配器后勾选接通。

### 5. 后续轨迹与卫星

来源候选为 NOAA GDAS/GFS + 独立 HYSPLIT、NASA FIRMS 等；ERA5/MEIC 用作区域背景时保留版本、年份、分辨率与时效。外部依赖与许可要现场核实，不从旧工具名称推定真实支持。

轨迹需有多起点/高度对照、气象驱动与输出验收；卫星需过境、质量和检出限制。执行与发布前完整复查业务、连接、当前选择、scope、取消与墓碑。默认部署不启用；启用前必须显式协调 `add-intelligent-tracing-multiagent` 的固定禁用要求、注册集合与会话能力文案，并保留旧失败工具禁用。首批不会修改其他任务已有未提交 delta 来制造一致。

### 6. 验收与渠道依赖

G0：严格按参数截断的录制执行器验证基线确被读取，充分/不足/失败反例，受控 HTTP 验证真实请求计数及拒绝零外呼。固定数据包括同一过程的全量与目标单窗对照，网格错时、几何未知、气象起报已知/未知、401/403/IAM 故障和跨 scope。

G1：使用合法真实受理身份和现有 MCP 回放郑州原问题，保存私有原始样本摘要、工具参数、覆盖和最终可见内容；没有测试身份或上游不可达时明确未完成。真实模型/实际 SDK/持久化/浏览器分别验收。原有 fixture 通过只能证明受控语义，不能证明该站诊断正确。

第三、四步在得到有效渠道后执行各自的真实样本正向与越权反例；不因当前没有渠道而从计划删除，也不阻止第一批有条件的修复交付。

## Risks / Trade-offs

- 历史范围增加使响应和样本量上升 → 合并重叠辅助区间、有界窗口、明确请求数与超时，维持共享快照缓存和逐发送授权。
- 基础事实增多使正文扫描/分节/旧 checkpoint 漂移 → 域内向后兼容字段，逐 claim 证据要求与旧报告回读回归，保持固定报告版本及摘要。
- 网格缺拓扑降低连片结论数量 → 如实降级，不靠猜造几何扩大结论；保留真实邻站证据。
- 所需真实接口未知 → 以用户确认“只有现有 MCP”为当前接入事实，外部渠道任务明确依赖授权和数据；严禁用合成源补齐真实验收。

## Migration Plan

先冻结当前基线及改动边界，新增规格和测试；按第一、二步实现并保存新证据目录。首批无数据库迁移和依赖变动。后续连接配置、依赖和轨迹策略各自检验、按当前实际主规格协调后启用。Git 保存、部署、同步规格与归档分别遵守用户后续授权；回滚只撤回本次代码，不覆盖旧报告或削弱身份/证据门禁。
