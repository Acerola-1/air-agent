# tool-artifact-lifecycle 规格增量

## Purpose

让完整工具原始数据和计算派生结果具有可靠的归档、归属、回读及生命周期，使用户能够追溯回答依据，同时避免无归属读取、虚假归档成功和无限增长。

## ADDED Requirements

### Requirement: 可靠归档与归属回读

系统 SHALL 完整保存超大原始数据及派生结果，并绑定用户、线程、运行和工具调用；仅当前已授权线程的数据可被读取，保存失败 MUST NOT 声称已归档成功。

#### Scenario: 写入失败

- **WHEN** 生产归档存储不可用
- **THEN** 返回明确失败状态和恢复信息，不生成虚假可读引用或宣称保存成功

#### Scenario: 越权读取

- **WHEN** 其他用户或线程提供一个有效归档 ID
- **THEN** 拒绝读取且不泄露载荷

#### Scenario: 旧记录

- **WHEN** 旧归档没有所有权信息
- **THEN** 不自动公开，保留既有聊天说明

### Requirement: 保留期与会话删除

系统 SHALL 默认将原始及派生归档保存 30 天，期限可配置；到期后回读明确失效，聊天正文、摘要与调用记录不因归档到期被自动删除；删除会话 SHALL 清理关联归档。

#### Scenario: 到期回读

- **WHEN** 归档达到保留期限
- **THEN** 不返回载荷，界面显示已过期，原聊天气泡仍可查看

#### Scenario: 删除会话

- **WHEN** 用户删除自己的会话
- **THEN** 关联原始及派生归档被清理，其他会话数据保持不变
