# Spec Delta

## MODIFIED Requirements

### Requirement: 联网数据的补充边界
联网搜索 SHALL 只用于补充 MCP 与知识库未取得的数据，包括政策公告、新闻背景和缺失的数字；同一数据冲突时 MUST 以 MCP 或知识库为准；网页数字 MUST 带来源与时间，MUST NOT 伪装成监测数据。规范性数值（具体限值、标准号、条款）MUST 只由本轮已核验知识库原文支撑，网页结果 MUST NOT 升格为标准规定。

#### Scenario: 与 MCP 数据冲突
- **WHEN** 联网结果与已取得的 MCP 监测数据在同一对象和时间上不一致
- **THEN** 回答采用 MCP 数据，联网内容仅作补充或省略，并说明来源差异

#### Scenario: 自有数据缺失
- **WHEN** MCP 与知识库都没有用户需要的数据，联网结果提供了可用数字
- **THEN** 回答可呈现该数字，但必须标注互联网来源与检索时间，并说明不是本系统监测数据

#### Scenario: 法规限值
- **WHEN** 用户询问具体法规、标准条款或限值，而本轮知识库未取得可核验原文
- **THEN** 回答 MUST NOT 把网页结果中的数字保留为模型所写的标准规定
- **AND** 该句 SHALL 换成服务端归因句，标明网页来源，并写明未经知识库原文核验
- **AND** 该限制 SHALL 只作用于对应句子，不得整篇否决同一回答中的其他内容

#### Scenario: 联网非规范数据与法规问题共存
- **WHEN** 用户问题涉及标准或限值，联网结果同时提供了发布时间、适用范围等非规范数据
- **THEN** 非规范数据 MAY 带互联网来源发布
- **AND** 规范性结论 SHALL 独立按知识库证据判定
