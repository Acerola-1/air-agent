# Spec Delta

## Purpose

为企业 Agent 的提问、运行尝试、回答版本和观测链路建立可信且持久的关联，让后续反馈、成本和需求分析可以定位同一业务对象，并在重复提交和网络故障后保持一致的计数。

## ADDED Requirements

### Requirement: 可信提问归属
系统 SHALL 在可信身份和会话授权后创建逻辑提问，保存租户、用户、成员、线程、用户消息及图标识；客户端自报身份 SHALL NOT 替代服务端身份，关联对象 SHALL 属于同一授权范围。

#### Scenario: 合法提问
- **WHEN** 活跃成员在当前企业的授权线程提交新问题
- **THEN** 系统保存唯一 request_id 及事发时成员归属快照
- **AND** 返回的关联 ID 不包含运行票据、凭据或原文之外的秘密

#### Scenario: 伪造身份或旧企业上下文
- **WHEN** 提交携带其他企业 ID、其他用户的消息关联或失效的上下文版本
- **THEN** 系统拒绝写入和启动运行，且不暴露其他企业对象是否存在

### Requirement: 提交幂等与歧义恢复
系统 SHALL 对同一成员、线程和提交键的同内容重放返回已有对象，对同键不同内容返回冲突；在运行受理结果未知时 SHALL 先校准，不得盲目启动第二次运行。

#### Scenario: 并发重放
- **WHEN** 两个并发请求使用同一提交键和相同语义内容
- **THEN** 仅产生一个逻辑提问和一次运行尝试
- **AND** 两个调用方取得相同关联结果或明确的受理中状态

#### Scenario: 同键不同内容
- **WHEN** 同一授权提交键被用于不同问题、图或操作类型
- **THEN** 系统返回冲突，已有提问与运行内容不被覆盖

#### Scenario: 上游已受理但响应丢失
- **WHEN** 上游已创建运行而受理方尚未保存确认便退出
- **THEN** 恢复流程关联已有运行或保留“受理结果待确认”
- **AND** 不因客户端重试再次执行同一业务操作

### Requirement: 尝试与恢复关联
系统 SHALL 区分新提问、失败后重试、重新生成及人工恢复。重试和重新生成 SHALL 关联原 request_id 并创建独立 attempt_id；同一平台运行的恢复 SHALL 保留其 run_id 并增加恢复记录；内部模型或工具重试 SHALL NOT 增加提问或运行尝试数。

#### Scenario: 重新生成
- **WHEN** 用户对某提问请求重新生成且提供新的操作幂等键
- **THEN** 原请求数不增加，新尝试与后续回答有独立 ID 和来源尝试关联

#### Scenario: 工具内部重试
- **WHEN** 同一次运行重试一个 MCP 调用三次
- **THEN** 逻辑提问和运行尝试各只计一次，工具尝试留待观测契约记录

#### Scenario: 人工恢复
- **WHEN** 用户在等待人工处理的运行提交授权恢复命令
- **THEN** 系统记录独立恢复操作并关联原平台运行，不创建新的逻辑提问

### Requirement: 回答版本可追溯
系统 SHALL 只为用户可见的回答版本建立 answer_id，并关联 request_id、attempt_id、run_id 和可用的 message_id；部分回答与最终回答状态 SHALL 可区分，内部推理、工具输出和草稿 SHALL NOT 被当作最终回答。

#### Scenario: 确认最终正文
- **WHEN** 六图任一图确认一条用户可见的最终正文
- **THEN** 系统保存该版本关联，重放不重复创建版本

#### Scenario: 停止后的部分正文
- **WHEN** 用户取消时已展示部分正文但未确认最终回答
- **THEN** 系统标记部分/未确认，不计为最终回答成功

#### Scenario: 一次运行包含多个可见版本
- **WHEN** 运行产生多条有各自消息标识的可见回答
- **THEN** 各版本独立关联，工具消息与内部辅助模型输出不混入回答集合

### Requirement: Trace 多重映射
系统 SHALL 支持同一运行关联多个 Trace，保存提供方、项目范围、来源及主 Trace 选择依据；缺失映射 SHALL 明确标记，不生成假 Trace 或无授权的控制台链接。

#### Scenario: 辅助 Trace 晚到
- **WHEN** 辅助模型 Trace 在主运行结束后到达
- **THEN** 映射幂等补充，已有主 Trace 不被无规则替换

#### Scenario: Trace 未启用
- **WHEN** 运行没有 Langfuse 数据
- **THEN** 运行仍可回读，观测映射覆盖率显示缺失
