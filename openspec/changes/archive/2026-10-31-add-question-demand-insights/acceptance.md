# Change 7 独立验收矩阵

| ID | 场景 | 通过标准 |
|---|---|---|
| Q01 | A/B同用户与相似原句 | 向量匹配前限定企业；A聚类/计数/样本不见B，数据库非owner正反对照 |
| Q02 | 统计/运营/内容/manage权限 | metrics只有安全聚合；来源双权限；维护三权限；root无用户名旁路 |
| Q03 | 真IAM授权/撤权/切企业/过期 | 正常API配码/精确内省，队列后撤权外呼0；每批/发送前/提交重查，不把fixture当真IAM |
| Q04 | request多attempt/resume/重复扫描 | 同来源版本和split不重复；模型重试不增加需求 |
| Q05 | 晚确认与晚补内容 | admitted_at老于扫描水位的来源仍被补入，没有永久漏扫 |
| Q06 | 多意图/追问/否定/敏感/注入 | 正确拆分、不能猜上下文、脱敏后才能外发，恶意原文无工具执行能力 |
| Q07 | 查询/原因/预测同主题 | 困难负例不同标准问题，城市/日期/因子slots可追溯 |
| Q08 | 向量空间/维度/候选上限 | 不跨企业/模型比向量，非法向量拒绝，超2000簇有capacity_review且无全表无限加载 |
| Q09 | 真模型160样本校准与留出 | 60/100隔离，留出precision>=98%、清晰意图覆盖>=60%、至少50自动项，关键误合并0；列出全部误差及样本区间 |
| Q10 | 并发建簇与抢任务/旧租约 | 有效关联唯一、租约栅栏生效、事务外外呼，旧worker无法覆盖 |
| Q11 | LLM/Embedding超时503/预算 | 对话不受影响，作业有界重试/暂停，未知usage不记0，不换未批准供应商 |
| Q12 | 多意图主题去重/七日边界 | 原子/request/users三计数分别可SQL复算，按原问题业务日入窗 |
| Q13 | 增长零基线/缺回填/部分日 | 新出现不报无穷增长；未处理历史不可比，同长度/同截止对比 |
| Q14 | 负反馈/停止/多意图关联 | 标请求级证据，未评价不等未解决，不能逐意图复制成确定错误 |
| Q15 | 改名/合并/拆分并发 | 稳定ID/重定向无环、来源分配完整、CAS冲突与幂等无重复审计 |
| Q16 | 模型/阈值升级与半途失败 | 不混向量；新profile重算未完成仍读旧active，切换有覆盖/校准证据 |
| Q17 | 删除与原文到期/已发模型回包 | 文本、向量、原型、样本、摘要和贡献失效；晚到不重生；不宣称撤回已发输入 |
| Q18 | 恢复旧备份 | 重施墓碑、权限/委托有效期后才能开worker；旧原文和向量不复活 |
| Q19 | 真浏览器完整链与A→B→A | 真实来源到榜单/纠错/删除可追溯；窄屏键盘/IME/503、数据缺失状态正确 |
| Q20 | 规模/冷导入/最终集成 | design基准达标或如实阻塞；导入零模型网络，三图变化不重计问题，6页面完整接入 |

纯函数测试建议`admin/api/tests/demand_insights/test_{normalization,matching,statistics,versions}.py`；真实PG/远程IAM/worker测试建议同域`test_{access,jobs,privacy,integration}.py`，浏览器/组件在`admin/web/tests/demand-insights-*`。固定向量只验证算法/边界，不证明真模型归类质量。

至少准备同一request两意图、不同用户同意图、同用户两企业、恢复/重新生成、admission_unknown后确认、原文到期、模型运行中删除等确定性对照。合格/已处理/未归类/失败/缺源分别列，不能调分母隐藏困难样本。

证据写新的`docs/reviews/evidence/run/insights-<时间>/`，留出样本须脱敏，可提交小型无原句汇总。不得使用正式库故障注入、共享向量库或用户原文来凑验收。原始失败及协调者补修与实施模型评分分开，Token不可得记未采集。
