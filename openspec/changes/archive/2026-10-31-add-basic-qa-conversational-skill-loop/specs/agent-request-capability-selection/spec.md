## MODIFIED Requirements

### Requirement: 服务端验证与依赖冲突
服务端 SHALL 验证实际Graph的业务权限、能力归属、目录/材料版本、连接状态、选择长度及Skill工具依赖，不再要求普通Skill/MCP独立人员授权。未知、不可用、路径伪造、跨图选择在外呼前拒绝；显式Skill不被静默替换，也不因依赖缺失扩大用户选择。Basic QA 的领域数据工具还 SHALL 满足本轮 Skill 加载前置条件；该条件是业务执行策略，不是人员授权。

#### Scenario: Skill依赖被排除
- **WHEN** 显式Skill必需的MCP工具不在本次指定集合
- **THEN** 返回中文冲突说明，不启动模型或工具；依赖声明不自动授予权限或扩大选择

#### Scenario: 菜单确定性分析
- **WHEN** data-analysis当前菜单映射S1，用户提交S2
- **THEN** 拒绝不一致选择；一致S1且业务获准、依赖满足时可执行

#### Scenario: 无Skill的自动调用
- **WHEN** 用户有业务资格，使用自动模式且模型直接调用业务内有效MCP
- **THEN** Basic QA 的领域数据工具须先完成本轮有效 Skill 加载才可执行；其他图按原执行策略运行，不新增统一加载要求；所有图均无需成员工具绑定，仍按已受理范围执行

#### Scenario: 自动模式的运行时加载
- **WHEN** Basic QA 自动模式从目录直接加载或搜索后加载 Skill
- **THEN** 加载遵守受理时的工具选择并记录实际 Skill 及版本，不把模型选择改写为用户显式选择，不修改原幂等摘要

#### Scenario: 显式选择与追问冲突
- **WHEN** 本轮显式锁定 S1，但用户问题需要 S2
- **THEN** 不加载 S2，解释本次能力限制并引导用户以新提交调整选择，不把同线程上一轮选择当成本轮选择
