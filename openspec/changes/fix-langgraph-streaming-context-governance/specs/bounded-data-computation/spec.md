# bounded-data-computation 规格增量

## Purpose

提供当前会话归档数据上的受限编程计算，以可核验的范围、数量和结果替代原始大数据上下文，同时限制执行资源、外部能力和模型修正次数。

## ADDED Requirements

### Requirement: 完整结构化计算

系统 SHALL 允许模型依据问题和字段信息生成 JavaScript，对问题所需的完整归档数据筛选、排序、分组和聚合；固定业务规则 SHALL 使用受测试的实现，结果必须包含来源与覆盖状态。

#### Scenario: 目标在尾部

- **WHEN** 目标只在超过 12 万字符的尾部记录
- **THEN** 全量读取后找到目标，关键值与确定性基准一致

#### Scenario: 统计验证

- **WHEN** 请求全量排名或聚合
- **THEN** 按完整输入计算，处理记录数、缺失值与范围可追溯，无法确认完整性时不声称完整

### Requirement: 能力与资源边界

系统 SHALL 仅暴露当前会话的只读数据计算，不开放任意网络、shell、安装依赖或全部业务工具；计算任务隔离且大数据执行堆不跨轮持久化。默认 JS 时限 5 秒、heap 64 MiB，整理总限 90 秒和最多一次代码修正均可配置。

#### Scenario: 死循环或内存耗尽

- **WHEN** 脚本超限
- **THEN** 中止并回收执行资源，显示失败，不阻塞其他会话

#### Scenario: 输出超限

- **WHEN** 脚本返回过多数据
- **THEN** 保存有界引用或明确失败，不截断 JSON 后标记计算成功

#### Scenario: 修正用尽

- **WHEN** 一次自动修正后仍失败
- **THEN** 返回明确未完成，不用局部摘要冒充精确统计
