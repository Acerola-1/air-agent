# data-output-reduction 规格增量

## Purpose

对工具返回的业务错误、结构化和非结构化大输出建立完整覆盖且可失败的治理流程，使数据精简可回溯、重试符合错误性质，并保持原始工具调用协议。

## ADDED Requirements

### Requirement: 业务错误与有界重试

系统 SHALL 将参数校验、业务失败、服务故障和空结果区分处理；参数校验错误不盲目重试，可重试服务故障执行有界重试，图中断必须传播。

#### Scenario: 400 业务响应

- **WHEN** 传输成功但载荷标记参数校验失败
- **THEN** 工具状态为错误且说明需要调整参数，不显示完成

#### Scenario: 临时故障

- **WHEN** 实际工具节点内发生可重试连接错误
- **THEN** 执行预定重试后成功或明确降级，错误处理不被内层吞掉

### Requirement: 非结构化数据完整摘要

系统 SHALL 按摘要模型可用预算分块处理完整非结构化数据，合并时保留目标、关键结论、时间、单位和来源；未完成覆盖 MUST NOT 声称目标不存在或摘要完整。

#### Scenario: 窗口变化

- **WHEN** 模型可用窗口变化且输入超过单批预算
- **THEN** 动态调整批次并处理全部范围

#### Scenario: 中间批次失败

- **WHEN** 部分块摘要失败或合并无法完成
- **THEN** 报告信息不足与覆盖状态，不输出伪完整结论
