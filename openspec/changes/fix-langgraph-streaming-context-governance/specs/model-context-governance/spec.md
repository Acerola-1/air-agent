# model-context-governance 规格增量

## Purpose

为持续多轮问答提供可验证的摘要覆盖边界和完整模型请求预算，在保留用户历史记录的同时约束主模型与摘要模型输入，避免遗漏未归纳事实或超过模型窗口。

## ADDED Requirements

### Requirement: 摘要覆盖水位与失败恢复

系统 SHALL 仅从模型工作上下文移除成功摘要覆盖的历史消息，按完整轮次推进覆盖边界，所有意图共享相同行为；完整聊天历史 SHALL 保持可回看。

#### Scenario: 跨意图连续对话

- **WHEN** 数据查询生成摘要后连续知识问答或闲聊
- **THEN** 新移出活跃轮次的事实先归入摘要，再从工作上下文移除

#### Scenario: 摘要失败

- **WHEN** 摘要为空、超时或覆盖校验失败
- **THEN** 覆盖水位保持不变，未覆盖消息不被当成已摘要移除

#### Scenario: 历史兼容

- **WHEN** 打开没有覆盖水位的旧线程
- **THEN** 旧摘要不作为排除新消息的依据，历史仍完整

### Requirement: 动态完整请求预算

系统 SHALL 分别配置主模型和摘要模型的名称、窗口、输出预算与安全余量，统计内容、调用参数、系统提示和工具定义；无法获取专用 tokenizer 时 SHALL 使用标明来源的保守估算。

#### Scenario: 累计当前工具超限

- **WHEN** 多个工具各自低于单工具阈值但累计请求超预算
- **THEN** 执行有界数据治理或明确拒绝模型调用，不绕过硬预算

#### Scenario: 模型配置变化

- **WHEN** 摘要模型窗口或输出预算改变
- **THEN** 每批摘要输入随可用 token 预算调整，无固定字符前缀上限

#### Scenario: 容量准确

- **WHEN** 后端准备或完成一次推理
- **THEN** 前端区分有效输入、最近消耗和窗口配置，不把 input+output 当工作上下文

#### Scenario: 专家模式问候转真实查询

- **WHEN** 未知分词器的模型在“你好”后收到普通城市空气质量查询
- **THEN** 字节数不冒充 token 数导致错误拒绝，工具定义可精简时为实际结果留出空间
- **AND** 用量拆分展示系统规则、聊天与工具结果、工具定义和请求开销，近似量有明确标识，回答完成后优先显示提供商实际输入
