# 图实现归位与公共层职责重构

## Why

Basic QA 的图、节点、状态和新版会话能力主要位于 `src/common/business_graph/`，数据分析的菜单策略、专用提示及两图共同使用的手写上下文控制流程也留在公共层。数据分析已暂停开发，这种归属使 Basic QA 的持续演进与封存代码互相牵连，需要让各图拥有完整实现，使公共层仅承载真正可复用的技术或业务能力。

## What Changes

- 全面审查 Python `src/` 的文件职责、命名与依赖，按明确清单迁移，而非只搬 `basic_qa_runtime.py` 等显眼文件；保留无关工作区改动。
- 将 Basic QA 的构图、节点、条件边、状态、提示组装、会话能力、Skill/MCP 搜索加载、专属执行与输入策略迁入 `src/basic_qa/`，不再以“通用业务图”名义承载单图实现。
- 数据分析保持当前旧业务行为、菜单、Skill、测试及公开入口；将它仍在公共层的专属策略迁回 `src/data_analysis/`，完成结构归位后继续封存，不回退到更早代码、不新增功能。
- 两图分别拥有完整的上下文控制流程：历史投影、摘要触发与覆盖、近期轮次保留、工具资料治理编排、超窗恢复、状态写回；不通过公共可变控制器联动演进。公共层可以保留独立的 Token 计量、容量计算、纯文本归纳等基础能力。
- 拆分混合模块，保留真正通用的工具执行机制、身份与租户保护、台账、观测、存储、通用提示和共享领域规则。图专属策略通过可信装配边界接入，公共层不得反向依赖图实现。
- 保留工具包装器入口和每次真实发送前的两层作用域检查；公共发送边界调用服务端可信装配的执行策略，策略、运行状态或披露证明缺失／异常时拒绝，代码级重试重新校验，不因删除反向导入而丢失第二层保护。
- Deep Agents 保持自己的图和摘要中间件结构；仅调整受到公共能力迁移影响的引用或装配，不引入另一套上下文控制流程。
- **BREAKING（仅内部 Python 导入）**：移除旧 `common.business_graph` 及旧公共上下文控制入口，不以转发文件、动态导入或别名包维持错误归属。仓库内调用方同步迁移；公开 Graph ID、图入口、业务接口、事件契约和持久化语义保持兼容。
- 增加架构边界、两图独立上下文、旧 checkpoint 恢复、真实执行授权和公共能力兼容验收；实现、独立验收、Git 保存和部署分别报告。

## Capabilities

### New Capabilities

无。本次不新增产品功能；目录归属与依赖约束在设计和验收矩阵中固定。

### Modified Capabilities

无。现有业务行为保持不变，使用 `.openspec.yaml` 的 `skip_specs: true` 标记纯结构重构，不为通过校验虚构功能规格，不创建 delta specs。

## Impact

- 主要涉及 `src/basic_qa/`、`src/data_analysis/`、`src/common/business_graph/`、公共上下文模块、`capabilities.py`、`prompts.py`、MCP schema 与执行边界、原生受理及必要的应用装配代码。
- 同步受影响的测试、探针、脚本、部署入口声明和当前维护文档；管理API的 `services/ledger.py` 自有Skill／菜单校验也接入同一可信图策略。前端、管理后台界面和 `intelligent_tracing/` 不做内部结构改造，不修改外部 IAM／RAG 仓库。
- 不新增数据库迁移、依赖升级、模型更换、提示内容优化或业务策略版本变更；移动相对路径不得改变 Skill 材料版本、MCP schema 摘要和索引身份。
- 合法业务流程保持不变；管理API现有菜单校验的 `except Exception: pass` 必须改为失败关闭，策略加载、匹配或结果解析异常均拒绝受理。单列这项已有安全缺陷的最小修复及异常行为差异，不把异常旁路当作必须保留的旧业务行为，不新增授权要求。
- 以当前工作区（包括未提交及未跟踪的 Basic QA v2 实现）为迁移基线。`revise-basic-qa-session-capabilities` 仍决定 BQA 行为，`simplify-model-window-compaction-trigger` 仍决定现有容量行为；本 change 只替换代码归属，不继承或完成它们尚未通过的验收项。
- 本轮只创建本 change 的计划文件，不修改产品代码、其他 change、主规格、私有配置和运行服务，不提交、推送、部署或归档。具体迁移清单、依赖装配、兼容策略及验收见 [design.md](design.md) 与 [tasks.md](tasks.md)。
