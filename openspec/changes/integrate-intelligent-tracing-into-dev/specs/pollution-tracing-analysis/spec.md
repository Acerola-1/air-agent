# Spec Delta

## Purpose

定义污染过程与来向线索分析从请求冻结、证据注册、质控、异常/空间/气象分析到受控报告的领域行为，确保六项污染物在统一证据规则下输出可复核、不可越级归因的结论。

## ADDED Requirements

### Requirement: 请求在数据查询前冻结

系统 SHALL 在委派数据任务前校验并冻结 `TracingRequest`，包含规范站点/区域、污染物、带时区时间窗、调查半径、基线窗口、分析策略版本、业务码/策略版本/权限和实际图；缺字段、站点歧义或时间歧义时 MUST 先补问，补问前不得发起数据查询。

#### Scenario: 缺少调查半径
- **WHEN** 用户未给出调查半径
- **THEN** 返回补问，不默认 10km，不发起站点或 MCP 查询

#### Scenario: 同名站点
- **WHEN** 名称匹配多个授权站点
- **THEN** 返回候选代码并要求确认，不以模型猜测选择

#### Scenario: 伪造业务字段
- **WHEN** 请求中的业务码、策略版本、权限或图与可信运行上下文不一致
- **THEN** 拒绝冻结，后续模型和 MCP 调用数为 0

### Requirement: 证据由执行层注册

证据 MUST 由取数/分析执行层注册，包含唯一 ID、analysis/revision、业务与策略版本、工具稳定 ID、数据产品/来源类型、抓取/有效时间、时区、单位、质量标志、样本数、原始摘要和派生关系；模型或浏览器 MUST NOT 构造、修改或自称验证证据。

#### Scenario: 模型提交证据 ID
- **WHEN** 模型在报告计划中提交未注册或跨作用域的证据 ID
- **THEN** 门禁拒绝发布，不重试模型洗白

#### Scenario: NWP 来源
- **WHEN** 使用历史模式气象产品
- **THEN** 证据保留起报时间、有效时间和预报时效
- **AND** 缺失时标记未知，不改称观测

#### Scenario: 网格与站点同源
- **WHEN** 网格来自同一批站点插值或来源关系未知
- **THEN** 证据记录同源关系，不作为独立交叉验证

### Requirement: 字段级质控与时间对齐

系统 SHALL 按字段应用哨兵和范围规则：`pblh=-1` 仅对该字段视为缺测，合法负 u/v 和真实零值 MUST 保留；浓度、气象和 NWP 数据 MUST 做时区转换、整点对齐、窗口过滤、重复处理和覆盖统计，不得全局把 `-1` 或负值当缺失。

#### Scenario: pblh 哨兵与负 u/v
- **WHEN** 同一行包含 `pblh=-1`、`u=-1`、风速 0
- **THEN** pblh 记为缺测，u 保留为 -1，风速 0 保留

#### Scenario: 非整点气象
- **WHEN** 气象时间戳不是整点
- **THEN** 该行不参与小时配对，并记录明确质量标志
- **AND** 不静默四舍五入

#### Scenario: 跨时区气象
- **WHEN** 气象时间戳使用 UTC，目标窗口使用 Asia/Shanghai
- **THEN** 先转换到窗口时区再配对，配对样本不因时区差异丢失

### Requirement: 异常与超标分开

系统 SHALL 区分统计异常、平台等级和法规超标；统计异常使用冻结基线、绝对变化下限和最短持续，基线或覆盖不足时输出“证据不足”，MUST NOT 输出“无异常”；缺少有效法规阈值时 MUST NOT 计算超标倍数。

#### Scenario: 基线不足
- **WHEN** 基线覆盖率或样本数低于冻结门槛
- **THEN** 结论为数据不足，不生成无异常或方向性结论

#### Scenario: 无异常
- **WHEN** 覆盖和基线充分且未触发冻结异常规则
- **THEN** 明确输出无异常，不制造风场或来源结论

### Requirement: 空间格局与过程解释分离

系统 SHALL 分别输出 `spatial_pattern` 和 `process_assessment`；多站同步或网格连片只证明区域现象，传输关联 MUST 同时具备空间有序、上风向先升、合理滞后和风场一致等附加证据，并保留共同静稳等替代解释；孤立异常 MUST 保留设备、缺测和微环境解释。

#### Scenario: 多站同步但静稳
- **WHEN** 多站同时升高、低风低边界层、无传播时序
- **THEN** 可输出区域现象或局地累积相符，不确认传输

#### Scenario: 有效邻站不足
- **WHEN** 半径内没有足够有效邻站
- **THEN** 空间格局为 unknown，并保留邻站覆盖不足限制
- **AND** 不输出 isolated

#### Scenario: 传输关联
- **WHEN** 上风向邻站先升、滞后相关和风场一致同时成立
- **THEN** 只能输出“与传输相符”的关联解释
- **AND** 必须列出反证、替代解释和无轨迹限制

### Requirement: 六项污染物独立口径

系统 SHALL 为 PM2.5、PM10、O3、NO2、SO2、CO 分别使用污染物画像、QC 范围、单位和评价口径；CO 使用 `mg/m3`，其余使用 `ug/m3`；O3 保留小时过程并计算日最大 8h，PM2.5 24h 滑动只作补充统计；不同单位或不同平均时段的原始浓度 MUST NOT 直接排序。

#### Scenario: O3 过程与评价
- **WHEN** 分析 O3
- **THEN** 小时序列用于过程与风场，日最大 8h 单独计算并处理跨日和缺测有效性
- **AND** 不用单小时值替代 8h 评价

#### Scenario: CO 单位
- **WHEN** 输入 CO 为 `ug/m3` 或 `mg/m3`
- **THEN** 按画像换算到 `mg/m3` 后再比较阈值和输出

#### Scenario: 多污染物排序
- **WHEN** 六项污染物单位或平均时段不一致
- **THEN** 不直接按原始浓度排序
- **AND** 首要污染物只采用平台字段或共享标准化依据

### Requirement: 风场和滞后只作关联

系统 SHALL 统一气象来向、u/v 分量、扇区边界、静风阈值和圆周统计；风向覆盖不足、静风主导或方向不稳定时 MUST NOT 给出方向级结论；0–6h 滞后相关只能表述为统计关联，MUST NOT 推导源距离、源概率或因果。

#### Scenario: 静风主导
- **WHEN** 静风比例超过冻结门槛
- **THEN** 不输出主导来向扇区，并保留静风限制

#### Scenario: 用户索要源距离
- **WHEN** 用户要求根据风玫瑰给出 5–10km 源距离
- **THEN** 说明无法从现有证据推导，不生成距离数字

### Requirement: 结论 allowlist 与受控报告

系统 SHALL 由确定性规则从可信发现生成 claim allowlist、证据引用和固定 limitations；模型只能选择 claim ID，不能新增事实或参数；发布前 MUST 生成不可变 `ValidatedReport`，聊天正文、画布、持久化和历史回读使用同一验证版本。

#### Scenario: 合法百分比
- **WHEN** 报告包含有来源的数据完整率或同步率
- **THEN** 百分比正常通过，不被禁词误拦

#### Scenario: 无禁词越级归因
- **WHEN** 模型草稿写“污染主要由西北工业活动造成”但没有百分比或企业名
- **THEN** 门禁拒绝该结论，不因缺少禁词放行

#### Scenario: 画布旁路
- **WHEN** 模型尝试向画布提交任意 HTML/Markdown 正文
- **THEN** 拒绝，画布只接受已验证报告引用和服务端渲染内容

### Requirement: 轨迹/PSCF 固定不可用

系统 MUST NOT 装配、发现或调用轨迹/PSCF 工具；`trajectory_unavailable` MUST 作为固定限制保留；用户要求轨迹分析时说明能力不可用，可改为现有证据允许的风场关联分析。

#### Scenario: 用户要求后向轨迹
- **WHEN** 用户要求轨迹或 PSCF
- **THEN** 返回能力不可用说明，实际轨迹/PSCF 请求数为 0

#### Scenario: 固定限制
- **WHEN** 生成任意 `ValidatedReport`
- **THEN** 报告包含轨迹、排放清单和化学组分缺失限制
