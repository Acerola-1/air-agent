# Design

## Context

仓库提供问答发送、SSE/台账关联解析、持续发压辅助类和资源监督工具。执行器采用 Locust 产品适配器，负责组合这些能力并生成可复算报告；该适配器待实现与验收。每轮冻结实际源码与运行配置。

## Goals / Non-Goals

目标是在当前 macOS 本机、实际模型与部署条件下，直接测出闭环并发的观察值、确认下界和具备相邻证据的本轮最大确认值；准备、执行、统计和结论可复查。

默认测量范围为 Basic QA Q1/Q2。其他图或负载使用独立 profile；容量结论限定在实际执行的范围和验证时长内。

## Decisions

### D1. 一套主流程和可复制输入

主流程、执行交接、计划/结果/报告模板统一放入 `docs/performance/`。计划记录授权、实例、源码、题库、模型、机器、SLO、资源保护、时间/逻辑请求及可执行物理用量上限；模板默认关闭真实调用。执行器在发送前验证计划兼容性和协议能力。

### D2. 默认闭环专项

保持当前真实链路，完成一个独立问答就补一个。阶梯为 1/2/5/10/15/20，随后每次 +5；每档稳定准备后持续测量，不发一批后空等。时长、样本、真实在途、SLO 和失败分母以主流程为准。候选及相邻档各两轮独立复测；资源/发压器先限只能报告下界。开放到达、长稳、突发/恢复、故障及浏览器按需另行冻结，不作为每次本地并发的前置。

### D3. 安全与内存诊断分开

资源监测覆盖发压器初始化和服务恢复，阈值由本轮计划说明并实际校准。正常服务、代表问答和监督能力通过后，从低并发开始。资源异常、采集失效或预算到限时停止新增负载，核对未知终态，并按启动归属收尾。

### D4. 指标绑定用户问题

首正文排除工具、心跳、推理与历史消息；当前 legacy 来源明确标注，不假称已经具备生产端语义单元。完整流结束与台账确认分别计时；失败、保护中止、超时和未知保留分母。成功吞吐按测量结束窗口计数，发送 cohort 单列。事实质量抽查与技术/体验容量分别声明。模型 TTFT、物理并发、Token/s 不能代替产品首正文和并发。

### D5. 工具状态与档案

Locust 负责用户调度，产品适配器负责 SSO 引用、独立线程、SSE、可信确认、预算及监督联动。配置通过本轮计划传入。各轮使用时间目录独立保存，索引按时间倒序登记。

## Risks / Trade-offs

- 本机与发压器共享资源会限制结论：分别采样，先到保护线时只给下界。
- 外部模型和工具配额漂移：绑定账号/时段，冻结输入、重试、观测，不能将一次结果外推为供应商全局上限。
- 有限样本与时长不足以证明长期稳定：逐轮展示分母和时长，不平均 P95；扩展另验。
- 当前流程尚缺适配：交接明确列实现与有界模拟验收，不输出未经核验的现成执行命令。

## Implementation Plan

校验流程、模板、索引和引用，实现 Locust 产品适配器并完成有界协议与资源验收。按已授权计划执行真实测试，记录完整条件，所有结果由实际请求与采样生成。
